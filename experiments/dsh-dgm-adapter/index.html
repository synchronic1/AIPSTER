Experiment 01 · DSH × DGM

A bounded gate for proposals an agent wants to make about itself.

The upstream DSH superagent records a proposal and drops it. This adapter takes that same proposal shape, binds it to a fixed synthetic fixture, runs deterministic acceptance predicates, and returns a sealed verdict with a repair brief. It never applies, promotes, merges or executes anything.

    What this does not show

    • No model ran. These verdicts are deterministic predicate results, not model judgement.
    • Fixtures are authored and small: seven work items, fourteen artifacts, eight predicates.
    • Pass rates are fixture-relative. A different contract would produce different numbers.
    • Fewer work units is not an improvement; it is a smaller predicate set.
    • The comparison column excludes upstream's human pull-request review, so it is a no-gate reference point, never an upstream or model measurement.
    • Seals are unkeyed SHA-256: they prove a record was not altered, not who produced it. Selection re-derives a verdict from its fixture instead of trusting its seal.
    • The fixtures passed to selection are trusted input: a forged fixture would reproduce by construction. Re-derivation proves consistency with the supplied fixtures, not their authenticity.
    • Request validation covers JSON values. An in-process caller passing an object with a throwing getter or Proxy can still provoke an exception; JSON.parse cannot produce that shape.
    • The runtime no-effect probe runs in Node and covers the Node-side path only. The browser surface of this page is checked by manual QA, not by that probe.
    • The adapter reads no repository, token, webhook, account or live ticket.
    • Nothing here is production-ready, and nothing here is connected to a running system.

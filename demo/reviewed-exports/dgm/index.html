Reproduce

This is a standalone artifact. Every recorded value is embedded in this one file, so the demonstration needs no checkout, build, package install, server or network access:

  1. Save this file.
  2. Open the saved file directly in a current browser (a file:// URL).
  3. Open or close a case to display its prerecorded outputs. Nothing is imported, executed, scored or promoted.

The page has no scripts and loads no external resources, so it renders the same from a local file as from a web host.
